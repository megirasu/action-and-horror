#h1Catching Sphere

##概要
Unity で個人制作した 3D アクションゲームです。プレイヤーは、逃げていく「光」を追いかけながら、背後から迫る「黒い霧」から逃れ、最後は敵との撃ち合いを経てゴールを目指します。
コンセプト
追いかける「光」を"夢"、迫りくる「黒い霧」を"現実"に見立てています。夢を追い続けることと、それに迫る現実との緊張感を、追走と逃走というゲーム性で表現しようと試みました。(※ストーリー性をゲーム内で十分に表現しきれなかった点は、今回の課題として認識しています。

##操作方法
移動:WASD キー
視点:マウス
ダッシュ:左シフト
射撃:左クリック
エイム(照準):右クリック
リスタート(ゲームオーバー時):スペースキー

##主な実装
三角関数(サイン波)を用いた、光オブジェクトの浮遊・移動
ウェイポイントによる経路移動の制御
画面中央の照準方向へ発射する射撃システム、弾数制限とリロード
敵 AI(プレイヤーへの追跡・射撃)
プレイヤー/敵の HP 管理と当たり判定、HP バー・弾数の UI 表示
トリガー判定によるゲームオーバー/ゲームクリアの分岐

##プレイ動画

制作について
制作期間は約1週間と数日間です。無料アセットやシェーダーの導入でバージョン差によるトラブルに時間を取られ、当初想定したクオリティには届きませんでした。

この経験から、装飾より先にゲームの核を固めること、技術的リスクを見越した時間配分の重要性を学びました。また、AI ツールに頼りきることを避け、できるだけ自分で調べ、理解しながらコードを書くことを意識しました。
