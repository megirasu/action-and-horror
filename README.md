# Catching Sphere
### 作成したスクリプトはすべてAssets/Scriptsに保存しています。Soundsに関しては作曲家も行いました。
Assets/
├── Scripts/       # 作成したスクリプト一式　　
├── Sounds/        # オリジナル音源　　
├── Scenes/  
└── Prefabs/  

## 概要
Unity で個人制作した 3D アクションゲームです。
プレイヤーは、逃げていく「光」を追いかけながら、背後から迫る「黒い霧」から逃れ、最後は敵との撃ち合いを経てゴールを行うというものです。
私が大好きなアクションゲーム(TombRaiderやアサシンクリード等)に影響を受けて作成しました。
## コンセプト
追いかける「光」を夢や希望、迫りくる「黒い霧」を現実や失敗に見立てています。
追いかけ、追われるというまさに現実でよくあるようなことを、ゲーム的に表現できたらと考えました。
しかしそのような要素は力不足により表現できなかった。

## 操作方法
移動:WASD キー

視点:マウス

ダッシュ:左シフト

射撃:左クリック

エイム:右クリック

リスタート:スペースキー

## 主な実装
・三角関数を用いた、光オブジェクトの浮遊・移動
・ウェイポイントによる経路移動の制御
・画面中央の照準方向へ発射する射撃システム、弾数制限とリロード
・敵の簡単な動きと簡単な攻撃
・プレイヤー/敵の HP 管理と当たり判定、HP バー・弾数の UI 表示
・トリガー判定によるゲームオーバーやゲームクリアの分岐

## 制作について
制作期間は約3週間です。無料アセットやシェーダーの導入でバージョン差によるトラブルに時間を取られ、当初想定したクオリティには届きませんでした。
そこで途中からビジュアルの優先度を下げ、とにかくプログラムを書き形にすることに努めました。
開発する時の見通しを立てることの重要性や、コメント文の重要性を感じました。
しかしコメント文をどこまで書けば良いのか学校の授業の時からわからず、なんとなくで書いています。また足音はUnityStarterAssetsのアニメーションに音声が付属できなかったため、地面に接地している間、一定間隔で複数の効果音をランダムに再生することで擬似的に再現しました。また着地音は、1フレーム前が空中かつ現在は接地している瞬間を検出して再生するようにしています。
また、AI ツールに頼りきることを避け、できるだけ自分で調べ、理解しながらコードを書くことを意識しました。

## 今後の課題
